# 数据新闻 AI 工坊

一个可在本地与公开网页运行的教学原型，用于把数据新闻问题转化为结构化的 AI 协作任务。

## 已实现

- CSV、Excel、JSON 文件的浏览器端解析
- 数据集信息、字段类型与字段角色配置
- 独立的数据清洗环节，可勾选六类质量检测维度
- Node 清洗分析接口，可生成质量分、问题证据、处理建议和 Pandas 操作代码
- 分析思路与可视化思路的顺序选择和自动匹配
- 参考代码粘贴与迁移目标设置
- 规划、执行、核验三阶段提示词生成
- 对话式 AI 与编程智能体两种输出模式
- 提示词复制、Markdown 下载与本地草稿保存
- 与任务匹配的结果核验清单

## 本地运行

```bash
npm install
npm run dev
```

访问 `http://127.0.0.1:5175`。

## 构建检查

```bash
npm run build
```

## 在线部署与自动更新

项目针对 Vercel 配置了同源清洗 API。将仓库导入 Vercel 后，向生产分支 `main` 推送提交会自动重新构建并更新公开网址。

```bash
git add .
git commit -m "描述本次修改"
git push
```

本地运行时，文件先在浏览器中解析，抽样数据仅发送到同一台电脑上的 Vite 服务。在线运行时，抽样数据会发送到同源的 Vercel Function 完成即时诊断；当前代码不写入数据库或持久化存储。请勿向公开演示站上传含敏感个人信息的数据。

清洗规则位于 `server/cleaningEngine.ts`；本地接口注册位于 `server/cleaningPlugin.ts`，线上接口位于 `api/cleaning/`。新增或调整检测规则后，本地重新启动开发服务；推送到 `main` 后线上会自动生效。
